# RAG 复盘卡片

## 分块

固定大小适合快速基线；递归字符通过分隔符层级减少句子截断；语义分块把相邻句 Embedding 相似度作为边界信号；结构感知分块则把标题、页码和段落放入 metadata。分块没有绝对最优值，应通过检索命中率和回答引用准确率评估。

## 向量索引

Flat 的查询复杂度接近全量扫描，结果精确但数据大时慢；HNSW 建立多层近邻图，在速度和召回间平衡；IVF 先聚类再只搜索部分桶；IVF-PQ 进一步压缩向量。索引参数本质上是在延迟、内存和召回率之间取舍。

## 混合检索和重排

BM25 对词频和逆文档频率建模，适合精确词；向量检索对语义相近表达更鲁棒。由于两者 score 量纲不同，RRF 按排名计算贡献：`score(d) = Σ weight_i / (k + rank_i(d))`。Rerank 在候选已缩小后，用更强模型比较 query 和文档对，通常放在 RRF 之后。

## 常见线上问题

召回不全、切片缺上下文、引用与答案不一致、知识库更新残留旧向量、中文分词效果不稳定、长上下文挤压模型注意力、Prompt Injection、缺少离线评测和权限隔离，都是 RAG 系统比“能跑通 Demo”更难的地方。
